Lesson 0002

Write a Product Decision Function

Your first JavaScript win: turn a BetterBite product rule into code that can be tested. A function takes input, makes a decision, and returns a result.

Time: 10 minutes Skill: functions Case: similar swaps

Core move: JavaScript lets you make product judgment executable, one small decision at a time.

The Tiny Mental Model

Input

The function receives data. Here, the input is a food object with fields like category and texture.

Decision

The function checks conditions with if. Each condition represents a product rule.

Output

The function sends back a result with return. The caller can render, test, or store that result.

Read This Function

Read the code from top to bottom. Do not memorize syntax yet. Ask: what input enters, what decision happens, and what output leaves?

function suggestSwap(food) {
  if (food.category === "soda") {
    return "lower-sugar soda";
  }

  if (food.category === "fries" && food.texture === "crispy") {
    return "cleaner crispy potato snack";
  }

  return "similar cleaner option";
}
