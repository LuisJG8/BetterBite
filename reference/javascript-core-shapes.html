JavaScript Core Shapes

Most product code is built from a few repeatable shapes: values, objects, arrays, functions, conditionals, and returns. Learn to see those shapes before worrying about every language feature.

Value

A single piece of information.

const craving = "fries";
const sugarGrams = 39;
const isDrink = true;

Object

A named bundle of related values.

const food = {
  name: "Burger King fries",
  category: "salty snack",
  texture: "crispy"
};

Array

An ordered list of values or objects.

const swaps = [
  "Boulder Canyon chips",
  "air-fried potato wedges"
];

Function

A reusable decision or action.

function explainSwap(food, swap) {
  return `${swap} keeps the ${food.texture} experience.`;
}

Decision Shape

Shape
Use it when
Tiny example
if
The code must branch based on a condition.
if (food.category === "drink")
return
A function has decided its result.
return "sparkling water";
===
You want to compare values exactly.
food.texture === "crispy"
&&
Both conditions must be true.
salty && crispy

BetterBite rule: a JavaScript function is often a product decision made executable.
